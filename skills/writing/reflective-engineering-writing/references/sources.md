# 外部参考与融合取舍

- [Google Technical Writing](https://developers.google.com/tech-writing)：借鉴读者意识、知识诅咒、术语一致性、清晰句段、技术图示和多轮编辑。文档式结构不作为博客的强制模板。
- [IEEE-USA: How to Write a Compelling Technical Blog](https://insight.ieeeusa.org/articles/how-to-write-a-compelling-technical-blog/)：借鉴具体叙事、读者吸引力、信息型标题和视觉辅助。不强制篇幅、封面或 CTA。
- [PostHog: Writing blogs](https://posthog.com/handbook/engineering/writing-blogs)：借鉴工程经验选题、核心记忆点、真实试错、具体证据和作者声音。保留用户授权的代理写作模式，但严格约束作者立场和经历的真实性。

以上为此前资料分析的融合摘要，并非逐条复刻原文。外部指南是辅助方法，作者确认的理性乐观、独立思考和自然叙事具有更高优先级。
